# berryvision

| Módulo | Propósito |
|---|---|
| `audit.py` | Auditoría de solo lectura de datasets (imágenes, duplicados, anotaciones YOLO/COCO/LabelMe/Supervisely/VOC/CSV) |
| `optics.py` | Estimación de píxeles por milímetro según cámara y distancia (presets marcados como no confirmados) |
| `observation.py` | Contrato de salida propuesto (v0.1.0) y su validación |

Todavía no hay código de entrenamiento ni de inferencia: se añadirá en la fase 2 (`docs/08_roadmap.md`).
