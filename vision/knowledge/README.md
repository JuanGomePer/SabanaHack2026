# Biblioteca de conocimiento

El centro de referencia del módulo de visión: lo que se sabe, de dónde sale y qué se decidió.

| Archivo | Contenido |
|---|---|
| `sources.yaml` | Todas las fuentes (id S/D/R), con URL, fecha de consulta, licencia, confianza y estado de verificación |
| `decision_log.md` | Bitácora de decisiones (D-001…) |
| `agrar/` | Empresa, ecosistema verificado frente a reportado, jerarquía espacial |
| `robotics/` | AgiBot X2 Ultra (plataforma vigente) y Booster K1 (descartado, histórico) |
| `datasets/` | Catálogo, comparación, ranking y vacíos |
| `agronomy/` | Enfermedades objetivo y reglas de interpretación |
| `model_research/` | Herramientas candidatas, licencias y preguntas de investigación |

## Niveles de evidencia

Hecho (fuente primaria) · Fuente secundaria · Observación local · Hipótesis de ingeniería · Decisión · Pendiente.

Que una hipótesis aparezca en varias notas no la convierte en hecho. Las contradicciones entre fuentes se registran sin resolverlas a ojo.

No se copian documentos completos de terceros; solo resúmenes, metadatos y enlaces.
